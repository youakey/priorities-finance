# PRIORITIES — personal finance

Static presentation and interactive demo for the personal finance Telegram Mini App.

Live bot: https://t.me/iosif_finance_2026_bot

The public site contains synthetic demo data only. Real analytics require the owner’s Telegram session and are served by the existing backend. No tokens, credentials, databases or actual financial records are included in this repository.

Open index.html directly or serve this directory with any static server. All assets use relative paths and work under a GitHub Pages repository prefix.

The opening scene follows native scrolling and respects prefers-reduced-motion.
